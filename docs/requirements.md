# マラソントレーニング管理アプリ 要件定義

## 概要

マラソン出場に向けたトレーニングを支援するiOSアプリ。
iPhoneヘルスケアと連携し、ランニングデータや睡眠データを自動取得。
目標達成に向けた進捗管理とモチベーション維持をサポートする。

---

## 機能要件

### 1. ホーム画面

| 項目 | 内容 |
|------|------|
| 直近のマラソン大会表示 | 登録した目標大会までの残り日数、大会名、開催日を表示 |
| 今週のサマリー | 今週の走行距離、トレーニング達成率を表示 |
| クイックアクション | トレーニング記録、大会登録へのショートカット |

### 2. ヘルスケア連携

#### 2.1 ランニングデータ
- 走行距離
- 走行時間
- ペース（分/km）
- 消費カロリー
- 心拍数（取得可能な場合）
- ルート情報（取得可能な場合）

#### 2.2 睡眠データ
- 睡眠時間
- 就寝時刻・起床時刻
- 睡眠の質（深い睡眠、浅い睡眠など）

### 3. 週間メニュー管理

| 機能 | 説明 |
|------|------|
| メニュー表示 | 曜日ごとのトレーニング内容を表示 |
| テンプレート | 初心者・中級者・上級者向けの週間メニューテンプレート |
| カスタマイズ | ユーザーが自由にメニューを編集可能 |
| 休息日設定 | 休息日の自動提案・手動設定 |

### 4. 達成状況トラッキング

- 日次：その日のトレーニング完了/未完了
- 週次：週間目標に対する達成率（%）
- 月次：月間走行距離、トレーニング日数
- カレンダービュー：過去のトレーニング履歴を視覚的に確認

### 5. 目標管理

| 目標タイプ | 内容 |
|------------|------|
| 大会目標 | 参加予定のマラソン大会（日付、距離、目標タイム） |
| 週間目標 | 週間走行距離、トレーニング回数 |
| 長期目標 | フルマラソン完走、サブ4達成など |

## 画面構成

```
├── ホーム
│   ├── 次回大会カウントダウン
│   ├── 今週のサマリー
│   └── 本日のメニュー
├── 週間メニュー
│   ├── 週間カレンダー
│   └── 各日のトレーニング詳細
├── 記録
│   ├── ヘルスケアデータ一覧
│   ├── ランニング履歴
│   └── 睡眠履歴
├── 目標
│   ├── 大会一覧
│   ├── 目標設定
│   └── 進捗グラフ
└── 設定
    ├── ヘルスケア連携設定
    ├── 通知設定
    └── プロフィール
```

## 技術要件

### プラットフォーム
- iOS 17.0以上
- Swift / SwiftUI

### フレームワーク
- HealthKit：ヘルスケアデータの読み取り
- SwiftData：ローカルデータ永続化
- Charts：グラフ表示

### データ連携
- HealthKit API
  - HKWorkoutType（ランニングワークアウト）
  - HKCategoryType（睡眠分析）
  - HKQuantityType（距離、カロリー、心拍数）

---

## 非機能要件

### パフォーマンス
- アプリ起動時間：3秒以内
- ヘルスケアデータ同期：バックグラウンドで自動実行

### セキュリティ
- ヘルスケアデータへのアクセス許可をユーザーに明示
- データはデバイス内にのみ保存（クラウド同期なし）

### ユーザビリティ
- シンプルで直感的なUI
- ダークモード対応
- アクセシビリティ対応

## 用語定義

| 用語 | 説明 |
|------|------|
| ワークアウト | 1回のランニングセッション |
| メニュー | 1日のトレーニング内容（距離、種類など） |
| 達成率 | 設定した目標に対する実績の割合 |
